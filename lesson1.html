HTML តែមួយមុខ (Structure Only)

HTML បង្កើត រចនាសម្ព័ន្ធ។ វាប្រាប់ថាផ្ទះមាន បន្ទប់ ទ្វារ បង្អួច និងដំបូល ប៉ុន្តែមិនទាន់មានពណ៌ ឬភាពស្រស់ស្អាតឡើយ។

<button>Door</button>

HTML + CSS (Structure & Presentation)

CSS បង្កើត រូបរាង។ វាជួយលាបពណ៌ រៀបចំទីតាំង កំណត់ទំហំ តុបតែងជ្រុង និងធ្វើឲ្យផ្ទះមើលទៅស្រស់ស្អាត។

.door { background-color: brown; border-radius: 10px; }

CSS Syntax Breakdown

CSS Rule ជាទូទៅមានទម្រង់៖ selector { property: value; }

h1 {
color: blue;
font-size: 40px;
}

យក Mouse ដាក់លើផ្នែកនីមួយៗនៃកូដ (Hover) ដើម្បីមើលការពន្យល់លម្អិត។

Selector (តើរចនាអ្វី?)

h1 គឺជា Selector។ វាប្រាប់ Browser ថាត្រូវយក HTML Element ណាខ្លះមករចនា។ ក្នុងករណីនេះគឺ Heading 1 (h1) ទាំងអស់។

Property (រចនាផ្នែកណា?)

color គឺជា Property។ វាគឺជាលក្ខណៈដែលយើងចង់ផ្លាស់ប្តូរ (ឧ. ពណ៌អក្សរ)។

Value (ដាក់តម្លៃអ្វី?)

blue គឺជា Value។ វាជាតម្លៃដែលផ្តល់ឱ្យ Property នោះ។ ដូច្នេះអក្សរនឹងមានពណ៌ខៀវ។

Property

font-size កំណត់ទំហំអក្សរ។

Value

40px កំណត់ឲ្យទំហំអក្សរធំដល់ 40 pixels។

តើពាក្យ Cascading មានន័យដូចម្តេច?

ពាក្យ Cascading សំដៅទៅលើរបៀបដែល Style Rules ច្រើនអាចត្រូវបានប្រើលើ Element មួយ ហើយ Browser ត្រូវសម្រេចថា Style ណាត្រូវយកមកប្រើ។

តួនាទីរបស់ CSS ក្នុងការរចនា User Interface (UI)

ចុចបើក Properties នីមួយៗដើម្បីមើលពីរបៀបដែល CSS ប្រែក្លាយ HTML ធម្មតាទៅជា UI ដ៏ស្រស់ស្អាត។

ជំហានទី១៖ Browser អាន HTML

Browser រកឃើញ <h1> និង <p> រួចបង្កើតជា Document Object Model (DOM) Tree។

h1 { color: blue; }
p { font-size: 18px; }

ជំហានទី២៖ Browser អាន CSS

Browser ទាញយកនិងអាន CSS Rules រួចបង្កើតជា CSS Object Model (CSSOM) Tree។

h1 <h1>
p <p>

ជំហានទី៣៖ Browser ស្វែងរក Selector (ផ្គូផ្គង)

Browser ស្វែងរក Elements ក្នុង HTML ដែលត្រូវនឹង CSS Selector (ឧ. រកគ្រប់ h1 ដើម្បីដាក់ពណ៌ខៀវ)។ វាបញ្ចូល DOM និង CSSOM ចូលគ្នាទៅជា Render Tree។

CSS2 និង CSS3

CSS ត្រូវបានអភិវឌ្ឍជាបន្តបន្ទាប់។ CSS3 បានបន្ថែមសមត្ថភាពក្នុងការរចនាដែលកាន់តែទំនើបដូចជា Animations និង Effects។

CSS2 (Styling មូលដ្ឋាន)
Box Model
  • Font, Color, Background
  • Margin, Padding, Border
  • Width, Height, Position
CSS3 (Styling ទំនើបជាងមុន)
Visual Effects
  • Rounded Corners (border-radius)
  • Shadows (box-shadow)
  • Transitions & Animations
  • Transform (Rotate, Scale)
