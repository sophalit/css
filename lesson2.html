រចនាសម្ព័ន្ធ CSS Syntax

ស្វែងយល់ពីតួនាទីរបស់ផ្នែកនីមួយៗក្នុងការសរសេរ CSS Rule។ សូមដាក់ Mouse ពីលើពាក្យនីមួយៗ។

h1 {
  color: blue;
}

សូមដាក់ Mouse លើកូដខាងលើ ឬចុចប៊ូតុងខាងក្រោម

ដើម្បីស្វែងយល់លម្អិតអំពីតួនាទីរបស់វា។

Selector (តើរើសអ្វី?)

ជាឈ្មោះ Element (ឧ. h1) ដែលប្រាប់ Browser ថា "រក HTML នេះហើយដាក់ពណ៌ឱ្យវា"។

Property (តើចង់កែអ្វី?)

ជាលក្ខណៈ (ឧ. color) ដែលប្រាប់ Browser ថាយើងចង់កែប្រែអ្វី (ពណ៌អក្សរ ទំហំ ឬផ្ទៃខាងក្រោយ)។

Value (តើចង់ដាក់តម្លៃអ្វី?)

ជាតម្លៃ (ឧ. blue) ដែលបញ្ជាក់ច្បាស់លាស់ពីអ្វីដែលយើងចង់បាន (ឧ. ចង់បានពណ៌ខៀវ)។

Declaration (សេចក្ដីប្រកាស)

color: blue; គឺជា Declaration មួយ។ វាជាគូរបស់ Property និង Value ដែលភ្ជាប់ដោយ : និងបញ្ចប់ដោយ ;។

Declaration Block

គឺក្រុមនៃ Declarations ដែលស្ថិតនៅក្នុងវង់ក្រចក { }។ វាអាចមានមួយ ឬច្រើន។

CSS Comment /* ... */

អត្ថបទសរសេរសម្រាប់អ្នកសរសេរកូដអាន Browser មិនខ្វល់ពីវាទេ។ ជួយពន្យល់កូដកុំឱ្យភ្លេច!

វិធីសាស្ត្របញ្ចូល CSS

ពី Inline ដែលរញ៉េរញ៉ៃ ទៅ External ដែលមានរបៀបរៀបរយ។ សូមចុចប៊ូតុង "Refactor" ដើម្បីមើលកូដផ្លាស់ទី!

index.html
<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
</head>
<body>
  <h1 style="color: red;">CSS</h1>
  <p>This is a paragraph.</p>
</body>
</html>
style.css
/* មិនទាន់មាន File នេះនៅឡើយទេ */

Inline CSS

សរសេរ CSS ផ្ទាល់ក្នុង HTML Tag តាមរយៈ style="..."។ សមស្របសម្រាប់កែធាតុមួយភ្លាមៗ ប៉ុន្តែបើមានច្រើនវានឹងធ្វើឱ្យកូដ HTML វែងនិងរញ៉េរញ៉ៃ។

រៀបចំ Folder និងការភ្ជាប់ (Linking)

តើត្រូវសរសេរ href="..." យ៉ាងដូចម្តេចឱ្យត្រូវ? សាកល្បងតភ្ជាប់ File HTML ទៅកាន់ CSS!
